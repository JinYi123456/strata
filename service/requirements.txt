# STRATA service — runtime dependencies.
#
# The service is a thin HTTP layer, so this is three packages and nothing more.
# Notably absent, and deliberately:
#
#   * python-multipart — uploads are JSON with base64 payloads, not form posts,
#     so the multipart parser is never imported.
#   * any database driver — storage is the filesystem or S3 + DynamoDB, behind
#     one interface in service/store.py.
#   * httpx — needed only by the test client and by the optional model-backed
#     decision layer, both of which are declared in ../requirements-dev.txt.
#
# Ranges rather than exact pins: these are stable, well-tested libraries whose
# minor releases do not change the API this service uses, and pinning them
# exactly only serves to refuse installation on interpreters that would work
# fine. requirements.lock records the exact set the project was measured on.
fastapi>=0.115,<1
uvicorn[standard]>=0.30,<1
pydantic>=2.9,<3
