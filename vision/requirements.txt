# STRATA vision core — runtime dependencies.
#
# The core targets OpenCV 5 specifically. The rewritten graph DNN engine, the
# neural feature module (ALIKED / DISK / LightGlue) and the USAC robust
# estimation framework are all OpenCV 5 APIs and have no equivalent in 4.x:
#
#   python -c "import cv2; print(cv2.__version__, hasattr(cv2,'ALIKED_create'))"
#   → 5.0.0 True
#
# OpenCV is pinned exactly because the API surface is the whole point. numpy is a
# range because OpenCV already constrains it to >=2 and the exact patch release is
# not something this project depends on - pinning it exactly would refuse to
# install on perfectly good interpreters for no benefit. The exact set this
# project was measured on is in ../requirements.lock.
opencv-contrib-python==5.0.0.93
numpy>=2.0,<3
